TheKing Idiomas

Política de Privacidade

Última atualização: 30 de setembro de 2026

O TheKing Idiomas é um app para aprender inglês e espanhol com a Bíblia. Esta página explica que dados usamos, para quê e como podes apagá-los. Seguimos a Lei Geral de Proteção de Dados (LGPD).

Sem conta

Podes usar o app sem criar conta. Nesse caso, o teu progresso (lições, XP, gemas, capítulos lidos, palavras guardadas) fica guardado só no teu aparelho e não é enviado para nenhum servidor.

Com conta (Liga, liga da igreja, progresso na nuvem)

  • E-mail e nome de jogador — para entrares na conta e apareceres no ranking.
  • Senha — guardada apenas de forma cifrada (hash PBKDF2); ninguém consegue ler a tua senha.
  • Progresso do app — para não o perderes ao trocar de celular.
  • XP semanal e liga — para o ranking semanal e para a liga da igreja (o teu nome e XP aparecem aos outros membros do mesmo grupo).
  • Convites — se entraste pelo convite de alguém, guardamos essa ligação para dar as gemas do convite.

Lembrete diário (opcional)

Se ligares o lembrete, guardamos o endereço de notificação do teu aparelho, o fuso horário e a hora escolhida, só para te enviar o aviso. Podes desligar a qualquer momento no Perfil.

Compras (versão web)

Os pagamentos são processados pela Stripe. Nós não recebemos nem guardamos os dados do teu cartão ou do Pix — só um número de encomenda e o valor, para entregar as gemas ou o Premium.

E-mails

Só enviamos e-mails quando pedes para recuperar a senha (serviço Brevo).

Tradutor

Quando usas o Tradutor, o texto que escreves (ou falas) é enviado ao serviço gratuito MyMemory (Translated) só para ser traduzido. Não envies dados pessoais no tradutor. O histórico das traduções fica apenas no teu aparelho.

Serviços usados

Alojamento do app: GitHub Pages. Servidores e base de dados: Cloudflare. Pagamentos: Stripe. E-mail: Brevo. Tradução automática: MyMemory. Não usamos publicidade, não vendemos dados e não usamos ferramentas de rastreio de terceiros.

Apagar a conta e os dados

Podes apagar a tua conta e todos os dados do servidor a qualquer momento: dentro do app (Liga → "apagar conta") ou nesta página: apagar a minha conta. Os dados são apagados na hora.

Crianças

O app não é dirigido a menores de 13 anos. Menores devem usá-lo com autorização dos pais ou responsáveis.
